# 🤝 Contributing to Boids Educational Project

Thank you for your interest! This is primarily a **learning resource** demonstrating AI-assisted education.

## 🎯 Project Purpose

1. **Learning Resource**: Shows how to learn React with AI assistance
2. **Reference Implementation**: Complete, tested flocking simulation
3. **Teaching Framework**: Reusable methodology for AI-assisted learning
4. **Community Example**: Best practices for educational projects

## 🎓 For Learners

### Want to Learn From This?

1. Fork the repo
2. Delete src/ folder to start fresh
3. Follow PLAN.md step by step
4. Use AI as your guide (not solver)
5. Compare with this reference

See LEARNING_GUIDE.md for detailed approach.

## 👨‍💻 For Contributors

We welcome contributions that enhance **educational value**!

### Good Contributions ✅
- Additional learning guides
- More comprehensive tests with explanations
- Documentation improvements
- Accessibility enhancements
- Performance optimizations with learning notes
- Bug fixes with educational context

### Not Needed ❌
- Features that complicate learning
- Complex dependencies
- Changes without educational justification

## 📝 Pull Request Process

1. Fork the repository
2. Create feature branch
3. Make changes with clear commits
4. Add/update tests
5. Update documentation
6. Open PR with educational justification

## 💡 Enhancement Ideas

- UI controls panel
- Video walkthroughs
- Interactive documentation
- More debugging worksheets
- Custom hooks extraction guide
- Performance profiling tutorial

## 🐛 Bug Reports

Bugs are learning opportunities! Include:
- Expected vs. actual behavior
- Code context and step number
- Error messages
- What you tried
